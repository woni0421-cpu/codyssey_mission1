입주민_커뮤니티_기획서.md

## 1. 누가 쓰나

- **주 사용자:** 같은 건물에 사는 입주민
- **이용 조건:** 건물 위치 인증을 통과한 사용자만 이용
- **관리자:** 미정  
  - 서비스 운영자가 할지
  - 건물 관리사무소가 할지
  - 입주민 대표가 할지 아직 정하지 않음

---

## 2. 무엇을 하려고

같은 건물 입주민끼리 생활 문제를 빠르게 해결하는 커뮤니티 앱이다.

### 주요 목적

- 층간소음 문제 공유
- 분실물 찾기
- 중고 거래 또는 나눔
- 물건 빌리기
- 공동구매 모집
- 배달 같이 주문하기
- 자유로운 입주민 소통

### 악용 방지 원칙

- 게시글 작성자에게 **1:1 채팅 요청 가능**
- **단체채팅은 제공하지 않음**
- `장터/나눔` 글은 **무조건 익명 작성 불가**
- 장터 글에서의 채팅도 **익명 불가**

---

## 3. 화면과 동작

### 3-1) 건물 위치 인증 화면

앱에 들어오면 가장 먼저 보이는 화면이다.

**동작:**
- 사용자의 현재 위치를 확인한다.
- 같은 건물 입주민으로 확인되면 홈 화면으로 이동한다.
- 인증 실패 시 동작은 아직 미정이다.

**미정:**
- 위치 인증 실패 시 재시도만 가능한지
- 주소 직접 입력 후 검토 요청이 가능한지
- 고객센터 문의 방식이 필요한지

---

### 3-2) 홈 화면

홈 화면에는 **최신 글 목록**을 보여준다.

**표시 내용:**
- 최신 게시글 목록
- 글쓰기 버튼
- 카테고리 이동 버튼
- 마이페이지 이동
- 채팅 목록 이동

---

### 3-3) 기본 카테고리

게시판은 다음 7개 카테고리로 나눈다.

| 카테고리 | 예시 제목 | 본문 초반 예시 | 작성자 표시 |
|---|---|---|---|
| 자유게시판 | 엘리베이터 공사 시간 아시는 분? | 오늘 아침부터 안내문이 붙어 있던데 정확한 시간이... | 익명 또는 닉네임 |
| 분실물 | 1층 로비에서 키링 보신 분 | 어제 저녁 8시쯤 1층 로비를 지나갔는데... | 익명 또는 닉네임 |
| 장터/나눔 | 전자레인지 판매합니다 | 1년 정도 사용했고 작동 잘 됩니다. 직접 가져가실 분... | 닉네임 필수 |
| 빌려주세요 | 전동드릴 잠깐 빌려주실 분 | 커튼 설치 때문에 10분 정도만 필요합니다... | 익명 또는 닉네임 |
| 공동구매 | 생수 같이 주문하실 분 | 묶음으로 사면 배송비가 줄어서 같이 주문하실 분 찾습니다... | 익명 또는 닉네임 |
| 배달 같이하기 | 오늘 저녁 치킨 같이 시키실 분 | 최소 주문 금액 때문에 같이 주문하실 분 구해요... | 익명 또는 닉네임 |
| 층간소음 | 밤 11시 이후 소음 관련해서요 | 최근 며칠 동안 늦은 시간에 쿵쿵거리는 소리가 계속... | 익명 또는 닉네임 |

---

### 3-4) 카테고리별 게시글 목록 화면

카테고리를 선택하면 해당 카테고리의 글만 보여준다.

**게시글 목록에 표시할 내용:**
- 제목
- 본문 초반 내용
- 익명 여부 또는 작성자 닉네임

---

### 3-5) 글쓰기 화면

사용자가 게시글을 작성하는 화면이다.

**입력 내용:**
- 카테고리 선택
- 제목 입력
- 본문 입력
- 익명 작성 여부 선택

**규칙:**
- 대부분의 카테고리는 익명 작성 가능
- `장터/나눔` 카테고리는 익명 작성 불가
- 장터 글은 작성자 닉네임이 반드시 표시됨

---

### 3-6) 게시글 상세 화면

게시글을 눌렀을 때 보이는 화면이다.

**필요한 요소:**
- 제목
- 본문
- 작성자 닉네임 또는 익명 표시
- 댓글 목록
- 대댓글 목록
- 댓글 작성
- 댓글 익명 선택
- 신고 버튼
- 작성자에게 1:1 채팅 요청 버튼
- 본인 글일 경우 수정/삭제 버튼

**장터 글 규칙:**
- 익명 작성 불가
- 작성자 닉네임 표시
- 채팅도 익명 불가

---

### 3-7) 댓글 기능

댓글에는 다음 기능이 필요하다.

- 댓글 작성
- 대댓글 작성
- 댓글 익명 작성 선택
- 댓글 신고
- 본인 댓글 수정/삭제

**미정:**
- 댓글 수정/삭제 기록을 남길지

---

### 3-8) 채팅 목록 화면

내가 참여 중인 1:1 채팅 목록을 보여준다.

**표시 내용:**
- 상대방 닉네임
- 연결된 게시글 정보
- 최근 메시지 미리보기

**규칙:**
- 게시글 작성자에게만 채팅 요청 가능
- 단체채팅은 제공하지 않음

---

### 3-9) 1:1 채팅 화면

게시글 작성자와 대화하는 화면이다.

**기능:**
- 메시지 보내기
- 메시지 받기
- 연결된 게시글 확인
- 채팅 신고 기능은 필요할 수 있으나 세부 방식은 미정

**장터 글 채팅 규칙:**
- 익명 불가
- 닉네임 기반으로 대화

---

### 3-10) 신고 화면

게시글, 댓글, 채팅 메시지를 신고하는 화면이다.

**신고 대상:**
- 게시글
- 댓글
- 채팅 메시지

**신고 사유 예시:**
- 욕설/비방
- 도배
- 사기 의심
- 개인정보 노출
- 기타

**미정:**
- 신고 후 누가 처리하는지
- 신고가 몇 번 쌓이면 제재되는지
- 허위 신고 처리는 어떻게 할지

---

### 3-11) 마이페이지 화면

사용자 개인 정보를 확인하고 관리하는 화면이다.

**필요한 기능:**
- 내 정보 확인
- 닉네임 수정
- 위치 인증 상태 확인
- 내가 쓴 글 목록
- 내가 쓴 댓글 목록
- 채팅 목록 이동
- 신고/징계 상태 확인
- 로그아웃

**미정:**
- 닉네임 변경 횟수 제한 여부
- 위치 인증을 다시 해야 하는 주기

---

- 제목

- 수정 시간

## 5. 완성 기준

### 1차 완성 기준

1. 사용자가 앱에 들어오면 건물 위치 인증 화면을 먼저 볼 수 있다.
2. 위치 인증에 성공한 사용자만 홈 화면에 들어갈 수 있다.
3. 홈 화면에서 최신 글 목록을 볼 수 있다.
4. 7개 기본 카테고리로 게시글을 나눠 볼 수 있다.
5. 글 목록에서 제목, 본문 초반 내용, 작성자 닉네임 또는 익명 여부를 볼 수 있다.
6. 사용자는 게시글을 작성할 수 있다.
7. 사용자는 익명 작성 여부를 선택할 수 있다.
8. 단, `장터/나눔` 카테고리는 익명 작성이 불가능하다.
9. 게시글 상세 화면에서 제목, 본문, 작성자 정보, 댓글, 대댓글을 볼 수 있다.
10. 댓글과 대댓글을 작성할 수 있다.
11. 댓글도 익명 여부를 선택할 수 있다.
12. 게시글, 댓글, 채팅 메시지를 신고할 수 있다.
13. 게시글 작성자에게 1:1 채팅 요청을 할 수 있다.
14. 장터 글에서는 닉네임 기반으로만 채팅할 수 있다.
15. 단체채팅 기능은 제공하지 않는다.
16. 마이페이지에서 내 정보, 위치 인증 상태, 내가 쓴 글, 내가 쓴 댓글, 채팅 목록, 신고/징계 상태를 확인할 수 있다.

### 아직 정하지 않은 내용

- 관리자 역할을 누가 맡을지
- 관리자 화면을 1차 버전에 포함할지
- 위치 인증 실패 시 처리 방식
- 위치 인증을 다시 해야 하는 주기
- 신고 누적에 따른 징계 기준
- 게시글/댓글 수정 기록을 남길지
- 채팅 신고 후 처리 방식
