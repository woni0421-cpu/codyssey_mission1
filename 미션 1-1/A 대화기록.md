# 영화 티어리스트 웹페이지 개발 대화 정리

## 1. 프로젝트 개요

**프로젝트명:** 무비티어 / 영화 티어리스트 웹페이지  
**목표:** 사용자가 감상한 영화를 별점으로 평가하고, 점수에 따라 자동으로 S~E 티어에 분류하여 기록하는 웹페이지 제작

이 프로젝트는 학습용 웹페이지 예시로, 현재는 **외부 서버 없이 단일 HTML 파일**로 실행하는 형태를 목표로 한다.

---

## 2. 확정된 핵심 기획

### 사용자 목적

- 본인이 본 영화를 기록한다.
- 영화별 별점, 한줄평, 감상 여부를 저장한다.
- 별점에 따라 자동으로 티어가 분류된다.
- 자신의 티어리스트를 공유할 수 있다.
- 공개/비공개를 선택할 수 있다.
- 다른 사용자를 팔로우하거나 공개 피드를 볼 수 있는 구조를 고려한다.

---

## 3. 로그인 정책

### 확정 내용

- **소셜 로그인 필수**
- 예시 로그인 방식:
  - 카카오
  - 구글
  - 네이버

### 현재 단일 HTML 데모에서의 처리

실제 OAuth 로그인은 서버와 인증 설정이 필요하므로, 현재 데모에서는 버튼을 누르면 가상 로그인 상태가 되도록 구성한다.

---

## 4. 영화 평가 방식

### 별점

- 0점부터 5점까지 평가 가능
- 0.5점 단위 선택 가능

예시:

```text
0점, 0.5점, 1점, 1.5점, 2점, 2.5점, 3점, 3.5점, 4점, 4.5점, 5점
```

---

## 5. 티어 자동 분류 기준

별점은 0.5점 단위로 선택할 수 있지만, 티어는 1점 단위 기준으로 자동 분류한다.

| 별점 범위 | 티어 |
|---|---|
| 5점 | S |
| 4점 이상 5점 미만 | A |
| 3점 이상 4점 미만 | B |
| 2점 이상 3점 미만 | C |
| 1점 이상 2점 미만 | D |
| 0점 이상 1점 미만 | E |

### 예시

| 별점 | 티어 |
|---|---|
| 5.0 | S |
| 4.5 | A |
| 4.0 | A |
| 3.5 | B |
| 3.0 | B |
| 2.5 | C |
| 2.0 | C |
| 1.5 | D |
| 1.0 | D |
| 0.5 | E |
| 0.0 | E |

### 공유

## 9. 영화 데이터 API

### 확정 API

**TMDB API** 사용을 기준으로 기획했다.

### 사용할 영화 정보

| 정보 | 설명 |
|---|---|
| 제목 | 영화 제목 |
| 포스터 | 영화 포스터 이미지 |
| 장르 | 추천 및 분류에 활용 |
| 줄거리 | 영화 설명 |
| 개봉일 | 영화 메타 정보 |
| 검색 | 영화 검색 기능 |

### 현재 데모에서의 처리

실제 TMDB API를 사용하려면 다음이 필요하다.

- API 키
- 외부 요청
- 서버 또는 프론트엔드 API 연동 코드

현재 제작 중인 단일 HTML 파일은 외부 서버 없이 실행하는 데모이므로, 임시 샘플 영화 데이터를 사용한다.

---

## 10. 추천 방식

### 확정 방식

**장르 기반 추천**

### 동작 방식

1. 사용자가 평가한 영화들의 장르를 확인한다.
2. 높은 점수를 준 영화의 장르 점수를 누적한다.
3. 아직 평가하지 않은 영화 중 선호 장르와 겹치는 영화를 추천한다.

---

## 11. 화면 구성

### 메인 화면

- 내 티어리스트를 우선 표시한다.
- 평가한 영화들이 S~E 티어별로 나뉘어 보인다.

### 주요 섹션

1. 헤더
   - 로고
   - 로그인 상태
   - 공유 버튼
   - 초기화 버튼

2. 히어로 영역
   - 서비스 소개
   - 소셜 로그인 버튼

3. 내 기록 요약
   - 평가한 영화 수
   - 평균 별점
   - 가장 많은 티어
   - 공개 기록 수

4. 내 티어리스트
   - S, A, B, C, D, E 티어별 영화 카드 표시

5. 영화 검색 및 평가
   - 제목, 장르, 줄거리 검색
   - 장르 필터
   - 별점 선택
   - 한줄평 입력
   - 감상 완료 여부 선택
   - 공개 여부 선택
   - 저장/삭제 버튼

6. 장르 기반 추천
   - 평가 기록을 바탕으로 추천 영화 표시

7. 공개 피드
   - 공개 상태로 저장한 영화 기록 표시
   - 좋아요 데모 버튼

## 15. 대화 중 발생한 이슈

### 문제

단일 HTML 코드가 여러 번 답변 길이 제한 때문에 중간에 끊겼다.

### 현재 상태

- 앞부분 HTML/CSS/JS 일부가 작성되었다.
- 이후 이어붙이는 코드도 일부 제공되었다.
- 마지막으로 제공된 이어붙이기 코드는 `renderRecommendations()` 함수 뒷부분부터 `</html>`까지 포함했다.
- 다만, 중간에 잘못 적힌 짧은 코드 블록이 있었고, 해당 코드는 붙이면 안 된다고 안내했다.

### 주의할 점

이전 답변 중 아래처럼 불완전한 코드는 사용하면 안 된다.

```js
movie.genres.forEach genre => {};
```

올바른 형태는 다음과 같다.

```js
movie.genres.forEach(genre => {
  if (!genreScore[genre]) {
    genreScore[genre] = 0;
  }

  genreScore[genre] += Number(item.score);
});
```
