# 영화 티어리스트 웹페이지 기획서

## 1. 누가 쓰나

- **불특정 다수의 사용자**
- 영화를 본 뒤 자신의 평가를 기록하고 싶은 사용자
- 다른 사람의 영화 취향이나 티어리스트를 보고 싶은 사용자
- 소셜 로그인으로 서비스를 이용하는 사용자

> 아직 정하지 않은 것  
> - 어떤 소셜 로그인 제공자를 사용할지  
>   예: Google, Kakao, Naver 등

---

## 2. 무엇을 하려고

사용자가 본 영화를 기록하고, 별점에 따라 자동으로 티어리스트를 만들 수 있는 웹페이지를 만든다.

주요 목적은 다음과 같다.

- 본 영화 기록하기
- 영화에 별점 남기기
- 영화에 한줄평 작성하기
- 감상 완료 여부 저장하기
- 별점에 따라 자동으로 티어 분류하기
- 자신의 티어리스트를 공개 또는 비공개로 설정하기
- 다른 사용자를 팔로우하기
- 티어리스트를 공유하기
- 장르를 기반으로 영화 추천받기

---

## 3. 화면과 동작

### 3-1. 메인 화면

- 메인 화면에는 **내 티어리스트**를 우선적으로 보여준다.
- 사용자는 자신의 영화 기록을 티어별로 확인할 수 있다.

---

### 3-2. 로그인

- 사용자는 **소셜 로그인**을 통해 로그인한다.
- 로그인한 사용자만 자신의 영화 기록을 저장할 수 있다.

> 아직 정하지 않은 것  
> - 사용할 소셜 로그인 종류

---

### 3-3. 영화 검색

- 사용자는 영화를 검색할 수 있다.
- 영화 정보는 **TMDB API**에서 가져온다.

가져올 영화 정보는 다음과 같다.

- 영화 제목
- 포스터
- 장르
- 줄거리
- 개봉일
- 검색 결과

---

### 3-4. 영화 기록

사용자는 영화마다 다음 정보를 저장할 수 있다.

- 별점
- 한줄평
- 감상 완료 여부

---

### 3-5. 별점 입력

- 별점은 **5점 만점**
- **0.5점 단위**로 선택 가능

예시:

- 0점
- 0.5점
- 1점
- 1.5점
- 2점
- 2.5점
- 3점
- 3.5점
- 4점
- 4.5점
- 5점

---

### 3-6. 티어 자동 분류

별점에 따라 영화가 자동으로 티어에 들어간다.

| 선택한 별점 | 티어 |
|---|---|
| 5점 | S |
| 4.5점 | A |
| 4점 | A |
| 3.5점 | B |
| 3점 | B |
| 2.5점 | C |
| 2점 | C |
| 1.5점 | D |
| 1점 | D |
| 0.5점 | E |
| 0점 | E |

정리하면, 티어는 **1점 단위 기준**으로 나누고,  
0.5점은 선택할 수 있지만 티어 분류에서는 **내림 처리**한다.

- 5점 → S
- 4점대 → A
- 3점대 → B
- 2점대 → C
- 1점대 → D
- 0점대 → E

---

### 3-7. 공개 / 비공개

- 사용자는 자신의 기록을 공개 또는 비공개로 설정할 수 있다.

> 아직 정하지 않은 것  
> - 공개 / 비공개를 티어리스트 전체에 적용할지  
> - 영화 기록 하나하나에 적용할지

---

### 3-8. 팔로우

- 사용자는 다른 사용자를 팔로우할 수 있다.

> 아직 정하지 않은 것  
> - 팔로우한 사용자의 기록을 어떤 화면에서 보여줄지  
> - 팔로우 목록 화면을 따로 만들지

---

### 3-9. 공유

- 사용자는 자신의 티어리스트를 공유할 수 있다.

> 아직 정하지 않은 것  
> - 공유 방식  
>   예: 링크 복사, SNS 공유 등

---

### 3-10. 추천

- 사용자의 영화 기록을 바탕으로 장르 기반 추천을 제공한다.
- 사용자가 높은 별점을 준 영화의 장르를 활용한다.

> 아직 정하지 않은 것  
> - 추천 알고리즘의 구체적인 방식  
> - 추천 영화 개수  
> - 이미 기록한 영화를 추천에서 제외할지 여부

---

## 4. 필요한 자료

### 4-1. TMDB API 자료

사용할 API:

- **TMDB API**

필요한 영화 정보:

- 영화 제목
- 포스터
- 장르
- 줄거리
- 개봉일
- 영화 검색 기능

필요한 준비:

- TMDB API 키 발급
- TMDB API 사용 조건 확인

---

### 4-2. 사용자 자료

저장해야 할 사용자 관련 정보:

- 사용자 로그인 정보
- 사용자별 영화 기록
- 사용자별 공개 / 비공개 설정
- 팔로우 정보

---

### 4-3. 영화 기록 자료

영화마다 저장해야 할 정보:

- 영화 ID
- 별점
- 한줄평
- 감상 완료 여부
- 자동 분류된 티어
- 공개 / 비공개 여부

단, 공개 / 비공개가 영화별인지 전체 티어리스트 기준인지는 아직 정하지 않았다.

---

### 4-4. 추천에 필요한 자료

추천 기능을 위해 필요한 정보:

- 사용자가 평가한 영화 목록
- 각 영화의 장르
- 사용자가 준 별점
- 높은 별점을 받은 장르 정보

---

## 5. 완성기준

아래 기능이 동작하면 기본 완성으로 본다.

### 필수 완성 기준

- 소셜 로그인으로 로그인할 수 있다.
- TMDB API를 이용해 영화를 검색할 수 있다.
- 영화 제목, 포스터, 장르, 줄거리, 개봉일을 가져올 수 있다.
- 사용자가 영화에 별점을 줄 수 있다.
- 별점은 5점 만점, 0.5점 단위로 선택할 수 있다.
- 사용자가 한줄평을 작성할 수 있다.
- 사용자가 감상 완료 여부를 저장할 수 있다.
- 별점에 따라 영화가 자동으로 S~E 티어에 분류된다.
- 0.5점 단위 별점은 티어 분류 시 내림 처리된다.
- 메인 화면에서 내 티어리스트를 확인할 수 있다.
- 사용자가 공개 / 비공개를 선택할 수 있다.
- 다른 사용자를 팔로우할 수 있다.
- 티어리스트를 공유할 수 있다.
- 장르 기반 추천을 받을 수 있다.
