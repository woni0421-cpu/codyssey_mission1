# 내 영화 티어리스트

## 누가 쓰나

- 나와 영화를 좋아하는 친구들

## 무엇을 하려고

- 본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리합니다.

## 화면과 동작

- 위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드를 보여 줍니다.
- 카드를 누르고 등급 글자를 누르거나, 카드를 끌어 놓으면 해당 칸으로 옮겨집니다.
- 제목을 입력하고 ‘추가’를 누르면 아직 안 정한 영화에 카드가 생깁니다.
- 영화 목록과 등급 배치를 브라우저에 자동으로 저장합니다.
- ‘처음으로’를 누르면 처음 영화 목록과 배치로 돌아갑니다.

## 필요한 자료

- 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리

## 완성 기준

- 영화가 한 칸에만 있고, 옮긴 칸에 남습니다.
- 제목을 입력하면 새 영화 카드가 생깁니다.
- 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.
- 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.
- ‘처음으로’를 누르면 처음 영화 8개가 모두 미분류로 돌아갑니다.
- 외부 파일·로그인·서버 실행 없이 HTML 한 장으로 열립니다.
- 빈 제목은 추가하지 않습니다.

## 더할 기능

- 내 티어리스트 전체를 친구에게 공유할 수 있습니다.
- 친구도 자기 티어리스트를 만들 수 있습니다.
- 친구의 티어리스트 링크를 붙여넣어 친구를 맺을 수 있습니다.
- 친구 목록에서 친구를 선택하면 해당 친구의 티어리스트를 볼 수 있습니다.
- 영화 카드별로 좋아요/싫어요 반응을 남길 수 있습니다.
- 좋아요/싫어요는 누가 눌렀는지 보이지 않고 숫자로만 표시됩니다.

이번 버전은 실제 서버 없이 동작하는 **데모 버전**입니다.

- 외부 서버는 사용하지 않습니다.
- 실제 친구 추가 기능은 구현하지 않고, 예시 친구 목록을 미리 제공합니다.
- 실제 소셜 로그인은 하지 않고, 소셜 로그인 화면 또는 로그인된 상태를 흉내 냅니다.
- 친구의 티어리스트 링크 입력 기능은 데모용으로 제공합니다.
- 좋아요/싫어요 데이터는 예시 데이터 또는 현재 브라우저 안에서만 저장됩니다.
- 친구들 모두에게 반응이 보이는 것처럼 화면에 표시하지만, 실제 온라인 동기화는 하지 않습니다.

- 서비스 사용 전 소셜 로그인이 필요한 구조로 설정합니다.
- 데모에서는 실제 로그인을 하지 않고, 다음과 같이 표시합니다.

예시:

- `Google로 로그인`
- `Kakao로 로그인`
- `데모 계정으로 시작하기`

데모 계정으로 시작하면 로그인된 사용자처럼 서비스를 이용할 수 있습니다.

영화 카드를 클릭하면 상세창에서 반응을 확인합니다.
상세창 안에서 좋아요/싫어요 버튼을 누를 수 있습니다.

예시 상세창 구성:

영화 제목: 인터스텔라
등급: S

친구들의 반응
👍 좋아요 7
👎 싫어요 2

[좋아요] [싫어요] [닫기]
